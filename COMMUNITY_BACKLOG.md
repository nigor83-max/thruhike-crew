# Community backlog

The current public task scope is limited to safe factual observations about already-public ThruHike pages and repository documents. The current open Issues are published with an observation scope and acceptance criteria. They are not implementation assignments.

The project owner is the sole first maintainer/moderator. No response or completion time is promised. Do not submit pull requests, code, text, images, designs, maps, route data, or other materials until separate licensing and intellectual-property terms are approved. Do not post personal, private, sensitive, security, production, or credential information.

The website Crew application is open. Submit applications only through https://thruhike.ru/crew; `support@thruhike.pro` is only for privacy/data questions, consent withdrawal, and deletion requests. Use GitHub's private **Report a vulnerability** route for security findings.

Participation does not promise a schedule, payment, income, employment, equity, ownership, or other rights.
