# ThruHike Crew — first eight report-only Issues

These drafts are limited to safe observations on public pages and public repository documents. The project owner is the sole first maintainer/moderator. Every task is report-only: do not submit code, replacement text, images, design, maps, route data, private or personal information, security findings, or production access. A report may conclude that no issue was found. No response or completion time is promised. `support@thruhike.pro` is only for privacy/deletion requests; use GitHub's private Security reporting route for vulnerabilities.

## 1. Crew page: small-screen rendering check result

- **Direction:** Testing — public Crew page rendering.
- **Size:** Small (S).
- **Owner:** Repository maintainer.
- **Scope:** At one common mobile viewport, report a reproducible rendering issue or state that no issue was found. Check the RU and EN page if both are available.
- **Acceptance:** Include the public URL, language, viewport dimensions, browser, and steps. State the observable issue or explicitly say none was found. Evidence must be verifiable without login; sanitize any optional screenshot completely. No design or code proposal.
- **Safe handoff:** Post only public URLs and sanitized factual observations in this public Issue. Do not attach files, submit changes, access production/admin systems, or include personal, private, security, or location data.

## 2. Crew page: RU/EN wording parity check result

- **Direction:** Content QA — compare existing public RU/EN statements.
- **Size:** Small (S).
- **Owner:** Repository maintainer.
- **Scope:** Report whether existing RU/EN text has a materially different meaning or condition, including no discrepancy found.
- **Acceptance:** Link both public language versions and identify the reviewed sections with short exact excerpts, or state no discrepancy and name the sections checked. The finding must be verifiable from the current public pages. Do not write replacement copy or translation.
- **Safe handoff:** Submit only the public links and minimum excerpts needed to verify the observation. Do not attach content files, propose edits, or include personal/private information.

## 3. Crew page: keyboard navigation check result

- **Owner:** Repository maintainer.
